What each HTML file will cover

01. HTML Structure
DOCTYPE, html, head, title, meta, body, and the basic structure of an HTML document.
<!DOCTYPE html> 
<html lang="en"> -HTML
<head> -Header tag
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title> -Title tag
</head>
<body> -Body tag
    
</body>
</html>


02. Text Elements
Headings, paragraphs, bold and emphasis, line breaks, horizontal rules, quotations, and code text.

03. Lists
Ordered lists, unordered lists, description lists, nested lists, and list items.

04. Tables
Table, thead, tbody, tr, th, td, caption, colspan, and rowspan.

05. Forms
Form, labels, text inputs, email, password, radio buttons, checkboxes, select menus, textarea, and submit buttons.

06. Links and Images
Anchor tags, URLs, email links, opening links in new tabs, images, alt text, and image dimensions.

07. Embedding
iframe, embedded web pages, video, audio, and external multimedia content.

08. Semantic Elements
header, nav, main, section, article, aside, footer, and the importance of meaningful HTML structure.
